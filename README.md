# Computer Vision

This repository collects the notebooks I worked through while learning computer vision, from basic image handling with OpenCV up to deep learning models for classification, transfer learning, object detection, tracking, and instance segmentation.

## Contents

| Notebook | Topic |
|---|---|
| `1. CPUvsGPU.ipynb` | CPU vs GPU concepts for computer vision workloads and why GPUs matter for convolutions and deep learning. |
| `1. Drawing a Bounding Box with OpenCV.ipynb` | Basics of loading images and drawing bounding boxes with OpenCV. |
| `1. Tracking_fi.ipynb` | Object tracking vs. detection, classical trackers (KCF, CSRT, etc.) and multi-object tracking. |
| `2. Real-time Object Detection with YOLO.ipynb` | Real-time object detection using a YOLO model with OpenCV. |
| `3. Custom YOLO Object Detection with Roboflow.ipynb` | Training a custom YOLO detector on your own classes/annotations using Roboflow. |
| `Clasificacion_Celular_Manzana_Kernels_Convolucion.ipynb` | Binary image classification (phone vs. apple) using manual feature extraction with convolution kernels (edge detection, sharpening). |
| `CNN_PyTorch_CIFAR10.ipynb` | Building and training a custom CNN in PyTorch on CIFAR-10. |
| `Transfer_Learning_Clasificacion_Rostros.ipynb` | Transfer learning with PyTorch to classify a student's face vs. background images. |
| `Segmentacion_Instancias_YOLO.ipynb` | Instance segmentation with YOLO, generating pixel-level masks for detected objects. |

## Purpose

This is a personal learning repository, not a production project. The notebooks are ordered roughly by increasing complexity, moving from image fundamentals to full deep learning pipelines.
